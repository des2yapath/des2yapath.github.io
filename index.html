02 / SYSTEMS · ROBOTICS

Mini Lab Orchestrator.

An asynchronous Python controller orchestrating a simulated robotic laboratory workcell under transport fault injection.

  • Python (asyncio)
  • CRC32 Wire Protocol
  • State Machine
  • Fault Injection
  • Concurrency

Orchestrates multiple independent lab devices: two multi-axis positioning arms, a precision fluid dispensing pump, and an active reaction heater. Built on Python's native asyncio event loop without heavy external frameworks.

Implements a strict CRC32-checksummed binary wire protocol with sequence numbering, acknowledgement handshakes (ACK), backoff retries, and idempotent reply caches. It enforces spatial zone mutual exclusion to prevent physical arm collisions, and features instant emergency stop (e-stop) broadcast propagation when synthetic packet drops or latency spikes are injected.

03 / WEB · DATA SECURITY

AskSQL.

Converts natural-language questions into safe, validated, read-only SQL queries executed against Postgres.

  • React
  • TypeScript
  • FastAPI
  • PostgreSQL
  • sqlglot
  • Neon

Instead of naive string regex filtering, AskSQL uses sqlglot to construct an Abstract Syntax Tree (AST) of the generated query. It validates statement types, enforces a strict schema allowlist, and unconditionally rejects write mutations, drop cascades, and subquery tricks.

Backed by 13 automated security tests specifically targeting SQL injection and privilege escalation vectors. Executed under an isolated, least-privilege read-only role on Neon Postgres. Bundle size was reduced by 60% (615 KB → 248 KB) through route-based code splitting.

07 / AI · STATISTICAL ANALYSIS

AI Essay Detector.

Transparent, evidence-based AI writing detector using verifiable statistical signal extraction rather than a black-box model.

  • Python
  • FastAPI
  • Next.js
  • GPT-2 Medium
  • Pytest (200+ tests)

Built for the i12 HR Drive Hackathon (Callus). Instead of relying on subjective "LLM-as-a-judge" verdicts, it extracts 40+ deterministic stylometric features: sentence length variance, punctuation entropy, and token probability distributions.

GPT-2 Medium is used strictly as a frozen measurement instrument (one forward pass, per-token logprob and rank). Features are Z-scored against length-bucketed baselines from 480 verified human essays, delivering sentence-by-sentence empirical evidence.
