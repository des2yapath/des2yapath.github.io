# Divyansh Ahuja — Personal Portfolio

Live site: [https://des2yapath.github.io](https://des2yapath.github.io)

An editorial portfolio featuring an interactive smartphone interface, detailed technical deep-dives, and light/dark theme support. Built with pure vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Device Mockup & App Launcher**: Interactive phone UI with slide-up sheets.
- **Detailed Project Panels**: Highlighting recent projects in systems programming, cloud architecture, cyber security, and AI.
- **Dynamic Theming**: Light and dark mode with persistent user preferences (`localStorage`).
- **Accessible & Responsive**: Fully responsive layout from mobile (320px) to desktop, semantic HTML, and graceful non-JS fallback.

## Running Locally

Simply open `index.html` in any modern web browser or serve via:

```bash
python -m http.server 8000
```
